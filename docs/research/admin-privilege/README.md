## One-paragraph summary

Voice alone cannot carry this (NIST 800-63B-4 forbids voice as an authenticator; ASVspoof 5 shows clones still slip past best countermeasures). The defensible design is four independent layers: **F1** live-voice + anti-spoof as *candidate* detector (reuses the existing sherpa-onnx speaker embedder), **F2** camera face-ID + presentation-attack-detection ensemble (YuNet + SFace + MiniFASNet + rPPG + lip-sync — all Apache-2.0), **F3** a fresh random spoken challenge each session (kills replays/clones by construction), **F4** an Action Kernel policy with a hard `personal_domain` deny-list that no role can cross, enforced on canonical paths via already-built kernels (docs 140/88 + Worker admin tokens as the NIST "physical authenticator"). Enrollment is template-only: camera frames embed in RAM and are discarded; 3-8 encrypted 128-d centroids persist; nothing is ever "trained" on the admin's photos.

**Honest standing disclaimer:** all recognition layers are probabilistic; NEXUS's guarantee is *policy-deterministic* (F4 denies personal-domain and credential domains for every role) plus *layered probability* for identity. Nothing here claims certified identity assurance.
