Reminder Roll

One animation for every reminder. The digits roll from the time it is now to the time you asked for, NEXUS says it, and a small chip counts down beside the orb until it fires. Nothing here knows about maps: a trip, a call, a calendar event, a timer and a study slot all send the same event.

Now

Try a reminder

Keep the countdown on screen On: a small chip stays beside the orb for every reminder until it fires. Off: the reminder still fires on time and NEXUS still says it, but nothing stays on screen.

The event behind it

Every feature that sets a reminder sends this one event to the stage. The animation reads only these fields, so a new kind of reminder needs no new animation code. The switch above is the user's setting and always wins. A reminder can ask for no chip with display.countdown: false, but it can never show one when the user has turned the countdown off.
